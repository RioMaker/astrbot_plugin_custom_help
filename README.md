# astrbot_plugin_custom_help

替换 AstrBot 默认的 `/help` 帮助信息。插件会以高优先级处理 `/help` 和 `/帮助`，发送配置中的文本后停止事件传播，因此框架内置帮助不会重复回复。

## 要求

- AstrBot `>= 4.24.0`
- 无第三方 Python 依赖

最低版本设为 4.24.0，是因为较早版本曾存在“回复后停止事件传播状态被清除”的问题，可能导致自定义帮助和默认帮助同时发送。

## 安装

将整个 `astrbot_plugin_custom_help` 目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 的插件管理中重载或启用插件。

## 配置

打开 AstrBot WebUI，进入本插件的配置页面，在“自定义帮助内容”中填写需要输出的文本。支持多行文本，保存后发送：

```text
/help
```

也可以发送等价指令：

```text
/帮助
```

若配置内容为空，插件会返回内置提示，避免吞掉指令却不产生回复。

## 工作原理

- `help` 指令处理器使用优先级 `1000`，先于默认优先级为 `0` 的处理器运行。
- 回复前调用 `event.stop_event()`，阻止内置帮助及其他后续处理器继续处理同一事件。
