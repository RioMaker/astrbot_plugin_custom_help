# astrbot_plugin_custom_help

用可配置的多帮助块替换 AstrBot 默认 `/help`。根指令只汇总各插件的指令与一句简介，带块名称时返回该块的完整说明。

## 指令

```text
/help
/help <块名称>
/帮助
/帮助 <块名称>
```

示例：

```text
/help 绘图
/help 六爻
/help 介绍
```

块名称和别名均支持查询。例如为“绘图”配置“生图”别名后，`/help 生图` 会返回同一块内容。

## 总帮助与块详情

根 `/help` 只拼接所有启用且允许显示在总览中的“指令摘要”：

```text
可用指令

【绘图插件】
/生图 <提示词> — 根据提示生成图片
/生图状态 — 查看任务进度与配额

【六爻起卦】
/六爻 <问题> — 即时起卦并解读

发送 /help <块名称> 查看对应的详细帮助。
可用帮助块：绘图、六爻、介绍
```

`/help 绘图` 等子命令则依次返回该块的标题、简短介绍、指令摘要和详细说明。

## WebUI 配置

“帮助块”是可新增的模板列表，每个块包含：

- 启用状态
- 块名称与别名
- 显示标题
- 简短介绍
- 指令摘要：每行一条，建议采用“指令 — 一句话介绍”格式
- 详细说明
- 是否出现在根 `/help` 总览中

“介绍”“关于”等没有指令的块可关闭“在根 `/help` 中显示”，仍然可以通过 `/help 介绍` 单独查看。

## 图片与纯文本

“帮助输出方式”支持：

- `image`：默认。使用 Pillow 在本地快速绘制分组帮助卡片。
- `text`：发送纯文本。

图片渲染失败时会自动回退为纯文本，避免 `/help` 无响应。可选择柔紫、清蓝、青绿或玫瑰主题；系统没有可用中文字体时，可在配置中填写 `.ttf`、`.ttc` 或 `.otf` 字体路径。

## 安装要求

- AstrBot `>= 4.24.0`
- Pillow `>= 10.0.0`（AstrBot 安装插件时会从 `requirements.txt` 自动安装）

最低版本设为 4.24.0，是因为较早版本曾存在“回复后停止事件传播状态被清除”的问题，可能导致自定义帮助和默认帮助同时发送。

将整个 `astrbot_plugin_custom_help` 目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 的插件管理中重载或启用插件。

## 工作原理

- `help` 处理器使用优先级 `1000`，先于默认优先级为 `0` 的处理器运行。
- 回复前调用 `event.stop_event()`，阻止框架内置帮助继续处理同一事件。
- 图片模式使用 Pillow 本地绘制，不再启动浏览器型 HTML 截图。
- 相同配置和内容使用持久化 PNG 缓存；首次生成在线程中执行，之后直接复用缓存文件。
